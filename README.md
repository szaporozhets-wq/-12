Програма створена на мові C++, Розробники: Воробей М. і Запорожець С.. Програма є багатофайлова, вона вилучає з тексту слово, задане своїм порядковим номером.
Номер слова, що має бути вилучене згенеруване випадковим чином.
Програма складається з трьох файлів: main.cpp, FN.h та FN.cpp. У файлі FN.h оголошені прототипи всіх функцій та глобальна змінна для зберігання тексту. У файлі FN.cpp реалізовані самі функції, а main.cpp містить головну функцію, яка керує виконанням програми.
